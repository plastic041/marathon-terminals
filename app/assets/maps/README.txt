Overhead map SVGs rendered from Map.scen (Marathon 1), styled to match
the in-game overhead map.  Each SVG holds only geometry + class names;
all colours live in the shared map.css (linked from each SVG).
Lines are filtered like the game (flat interior lines between equal-
height polygons are omitted).  Classes: .poly/.poly-platform/
.poly-minor-ouch/.poly-major-ouch (floors), .wall/.elevation (lines),
.checkpoint (goal markers; index in a data-cp attribute).
Checkpoints are the locations shown by '#checkpoint n' terminals.
